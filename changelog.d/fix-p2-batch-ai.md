### Test and CI hardening (no operator-visible change)
- `npm run test:db` now ends with a skip census (`scripts/db-tier-census.mjs`): every file under `tests/db` must have executed at least one test and skipped none, or the run fails. A renamed or dropped `RUN_`/`REQUIRE_` pair, or a new gate on a variable the job never sets, now turns the DB job red instead of skipping green. Three skips are allowed by exact name (the built-artifact legs of `startup-option-verdict-across-bundles`, enforced in the job that builds, and the Unix-socket leg of `connection-schema-pinning`, which CI's TCP-only PostgreSQL cannot run).
- The A2 daily-sync test doubles now model `status` and `refundStatus`, so deleting either predicate from the eligibility filter fails a test.
- Added `markPostingHandled` tests that drive each term of the provably-unsent predicate on its own and assert a refused mark writes nothing.
- Fixed three test defects: a landed-cost retry test that compared an expression with itself, a source slice that ran to end-of-file, and two ordering checks that compared text positions (now parsed structurally).
- `paid-episode-database-clock` expects explicit UTC instants, so it no longer depends on the host timezone.
