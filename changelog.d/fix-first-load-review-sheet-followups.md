### Lifecycle review sheet follow-ups before the real import (first-load)
- An Archived decision is now checked against this run's WooCommerce stock for every product IMS loads, not only for products still in the review set: a product that was draft with stock 0 when the sheet was generated and has been published with stock since is refused Archived (unless the override reason is filled). A Mintsoft-discontinued row carried from the sheet takes this run's WooCommerce figure instead of "not read".
- A product name holding U+FFFD (a character lost in a conversion, from WooCommerce or Qoblex) no longer stops `first-load:lifecycle-review` with an internal error: the name is shown as it is, and U+FFFD is refused only in the four decision columns on read-back (IMS SKU, New IMS status, Override reason, Sheet id; .xlsx and both CSV forms). A review row whose SKU holds it is refused at generation (exit 3) naming the SKU.
- The Mintsoft credentials file is opened non-blocking, so a FIFO named as the file is refused at once instead of hanging the command; the sheet reader refuses a character XML cannot carry inside a CDATA section too.
- docs/first-load-input-spec.md: a one-off read-only probe of the live Mintsoft warehouse and stock endpoints, and the request budget, as an operator step before the real generation.
