### Slow-stock report for the period-end NRV review (inventory)
- New Analytics > Stock Position > **Slow Stock (NRV review)** report and `type=slow-stock` CSV export at `/api/export/stock-position`: per product (or per product and warehouse) on-hand quantity, on-hand value from FIFO layers, age of the oldest layer with stock, last sale date, units sold per 30 days over the last 90 days and months of cover. Filters: oldest layer age (for example 90, 180, 365 days), no sale in N days, warehouse, category, supplier, type and minimum value; sorted by value at risk. Supports the FRS 102 section 13.4 lower-of-cost-and-NRV review; write-downs are still manual stock adjustments.
- Read only, same access as the other stock-position reports; cost and value (including the value filter and CSV column) are hidden for roles without `inventory.prices`. Source scans are capped at 100,000 rows and refuse rather than truncate. No migration.
- Docs: help-docs/analytics.md (new section on using the report for the period-end review) and docs/architecture.md.
