### npm 11 install scripts and a UTF8 database on install (infra)
- `package.json` now carries an `allowScripts` policy: `prisma`, `@prisma/engines`, `esbuild`, `unrs-resolver` and `ssh2` may run their install scripts under npm 11 (Node 26); `cpu-features`, `fsevents` and `msw` are denied. The container image's generated migrate stage carries the Prisma entries too. `install.sh` and `update.sh` stop if `npm ci` left no Prisma schema engine, and `install.sh` no longer hides npm's install-scripts warning. A guard test pins the policy and requires every install-script package in the lockfile to be decided.
- `install.sh` creates the database `ENCODING 'UTF8' TEMPLATE template0` with an explicit locale (template1's pair when it fits UTF8, else `C.UTF-8`). `install.sh` and `update.sh` warn loudly when an existing database is not UTF8 (they never refuse: an existing SQL_ASCII installation is live data). See "Database encoding" in `docs/installation.md`.
