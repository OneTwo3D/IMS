### WooCommerce inbound: stale deliveries, secret rotation (woocommerce)
- A retried or replayed delivery that is older than the order's stored WooCommerce modified time no longer overwrites the address, notes, shipping method, VAT number, the duty/tax/handling components or the per-line customs unit values a newer delivery applied. The stored modified time now follows each applied delivery.
- Saving a new webhook secret keeps the previous one valid for 48 hours (stored encrypted), and "Setup Webhooks" now writes the current secret onto every existing matching webhook (duplicates included), so rotating the secret no longer silently refuses every delivery. A new "Revoke previous secret now" button in the WooCommerce settings clears the old secret immediately (use it when the old secret leaked). Signature checks are otherwise unchanged.
- Help docs: dead-lettered store webhook deliveries are visible and replayable under Sync > Exceptions (already the case); the rotation and revoke steps are documented.
