### Fix: three owner switches can now be set with `settings:set` (settings)
- `stock_adjustment_reason_cost_required`, `stock_adjustment_release_reserved` and `mintsoft_align_up_requires_receipt_evidence` are registered as ADMIN system switches (set with `npm run settings:set -- ... --yes --confirm-admin`), so they no longer need a hand-written SQL write. Their readers are unchanged: each reads exactly `true` and all default off, so behaviour with them off is identical and a stored `true` keeps working. Turning the reason-and-cost switch ON is refused while Xero sync is on and the inventory account is unmapped, and while no active adjustment reason exists (or, with Xero sync on, none has an account). The other two have no turn-on prerequisite.
