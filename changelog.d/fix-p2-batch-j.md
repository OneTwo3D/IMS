### Security: cost and margin data, cross-site requests, CSV formulas (dashboard / sales / API / exports)

- **Dashboard cost figures are Admin, Manager and Finance only.** COGS, profit, margin %, the Cash Bridge, the COGS and Margin % charts, Best Sellers margin and Inventory Value are withheld on the server for every other role (the figures are zeroed in the response and the cards are not drawn). Net sales, orders and stock counts are unchanged.
- **The sales-order form's COGS and margin estimate** (the COGS column, Est. COGS and Est. Margin) is shown only to Admin, Manager and Finance. Other roles can still create and edit orders; the server no longer sends them unit costs.
- **Cross-site requests to the API are refused.** Every state-changing (POST, PUT, PATCH, DELETE) request to a session-authenticated `/api` route (backup create and upload, manual sync, imports, accounting reconciliation and backfill, uploads, TOTP, step-up, notifications) must come from this site: a browser request marked cross-site or same-site, or carrying another site's Origin, gets 403. Signed webhooks, cron routes, the Xero OAuth callback, the shop and helper plugin signed handoffs and the dev-only rigs are exempt (decided from the route-auth policy). Script clients that send neither header are unaffected.
- **Two browser-built CSV exports now neutralise spreadsheet formulas:** the Manufacturing orders export and the Product Profitability export (a cell starting with `=`, `+`, `-` or `@` is prefixed with an apostrophe, as in every server CSV).
- Help documents: Dashboard, Sales.
