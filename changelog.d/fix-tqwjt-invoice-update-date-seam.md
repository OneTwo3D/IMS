### Invoice update date check shares the queue's decision, refuses unknown dates when live (accounting)
- Invoice update whose original date cannot be read: the date check now decides with the same inputs as the accounting queue (connector, update type, the date it would send), so a later writer-map change can no longer send today's date to Xero; the queue itself refuses any update flagged "date unknown" that would be sent. With the producer hold unset, the refusal fires only when an update would really be sent. The date-unknown warning is written inside the edit's transaction and only when the update was recorded as a shadow. The posted-date reader prefers synced rows. The customer timeline's same-day invoice ordering limit is documented.
