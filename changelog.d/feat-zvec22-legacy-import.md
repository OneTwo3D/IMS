### Legacy bridge order import and Step M precondition report (cutover)
- New `npm run cutover:legacy-import`: reads the legacy bridge's `_mintsoft_*` order meta from WooCommerce (read only) and writes IMS's own warehouse-order links so the push sweep never re-creates an order the bridge created (SYNCED, MERGED, DEAD_LETTER). Dry run by default; `--apply` also needs `--bridge-stopped` (recorded in the report and the activity log). Idempotent, never overwrites a differing link (a link naming the same id in another state is a conflict too). No migration; Mintsoft is not called unless the read-only `--verify-mintsoft` flag is given.
- The dry run is the Step M precondition report. It states `woocommerce_order_prefix` explicitly (production keeps it empty; any other value fails the gate), blocks on verify-pending bridge orders (not imported, since such a link could never verify) and queued bridge updates, fails when zero orders were read, says when the OrderNumber check is unverified against Mintsoft, and lists every non-empty bridge queue (including the writeback dead-letter, forced-terminal and resolved split parts) per order.
- The WooCommerce read pauses between pages and backs off on 429; `partially-shipped` is a default status.
