### Refunds spanning a journaled and a not-yet-journaled shipment

- **Fixed: a refund of units from two shipments, one already journaled and one waiting for the daily batch, restocked only one unit and lost the other's COGS credit.** Staging only sees journaled shipments, so the return used to restock just the journaled unit, and the daily batch then skipped the whole refund because it found a staged reversal. The return is now reconciled per source shipment: the journaled unit is restocked from the staged snapshot, the other unit from the shipment's issued cost, each at its own shipment's cost and each exactly once. The daily batch skips only the shares a staged COGS reversal already covers and books the rest (DR Inventory / CR COGS), so the Inventory debit equals the cost layers that came back and a rerun books nothing twice. No migration.
