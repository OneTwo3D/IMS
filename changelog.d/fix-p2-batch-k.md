### Inventory and costing fixes (purchasing, returns)
- A purchase receipt worth less than half a penny no longer queues a zero-amount stock receipt journal, from either the manual receipt or the WMS book-in.
- A manual purchase receipt now takes the stock row before writing the cost layer, the same order a supplier return uses (the WMS book-in keeps its existing order).
- Restocking a Mintsoft return that no refund expectation covers now books the units at the warehouse's average cost (else the product's historical average) with a cost layer. The value this adds is journalled in the same transaction (Dr Inventory / Cr COGS, as a manual stock addition is) so the ledger matches the cost layers. A product with cost layers at zero, or a non-inventory product, restocks at zero cost; a product with no cost layers at all is refused with a message to receive stock with a unit cost first, instead of adding stock at zero cost.
