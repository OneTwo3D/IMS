### Edit products by CSV round trip (inventory)

- **Added: Edit by CSV on the Inventory list.** Select products (or none, for everything matching the current filter) and pick the columns to edit from a picker. IMS downloads a CSV pre-filled with the current values for exactly that selection, variants included. Upload it back to see a per-product diff of what would change, then apply.
- **Update-only, and a blank is never a clear.** A blank cell leaves the field unchanged, a column absent from the file is not touched, an unknown SKU is rejected, and `__CLEAR__` empties a field, accepted only for nullable fields. Unrecognised values (a boolean, a number, a country, a category, a supplier) are row errors rather than silent defaults, and a row with any error writes nothing for that product.
- **Same follow-up as the editor, but paced.** Applied in batches of at most 250 products, each in one transaction and one set-based statement. The same transaction records the sync each product owes in a new `product_sync_marks` table (additive migration). Nothing is pushed to a vendor from the request: a new cron, `product-sync-marks` (on by default, every 5 minutes), hands 25 products per run to the storefront metadata push, the storefront stock queue, the warehouse product/bundle sync and HS-proposal invalidation that the product editor performs. A failed product is retried, then parked with its last error. The apply result tells the operator the changes reach the shop and warehouse over the next sync runs.
- **Scale.** Files of up to 50,000 rows / 25 MB, uploaded through a route handler instead of a server action; one SKU lookup per 1,000 rows. A test pins the round-trip count for thousands of rows.
- **Permissions.** Needs inventory edit; the price columns also need inventory prices, for download and for a file that contains them.
- **Stale files cannot overwrite newer edits.** The download ends with a `rev` column of per-value hashes. Only cells that differ from what was downloaded are applied; an edited cell whose field has since changed in IMS refuses its row, and the write itself only lands on a product whose `updatedAt` is unchanged since it was read.
- **Formula-guarded text round-trips exactly.** A cell is recognised as unedited by comparing against the downloaded value; the exporter's apostrophe is never stripped blindly, so stored text such as `'=SUM(1)` is not altered.
