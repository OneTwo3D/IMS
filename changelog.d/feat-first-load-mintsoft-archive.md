### Mintsoft archive plan for the owner's Archived decisions (first-load)
- New read-only command `npm run first-load:mintsoft-archive -- --manifest <run.json> --mintsoft-env-file <file>`: for every product the owner set to Archived on the lifecycle review sheet (and that the decisions would import), it lists whether it would be archived (discontinued) in Mintsoft, with the Mintsoft product id, the current DisCont flag and the physical stock, or why not (not found under the exact SKU, a bundle, already discontinued, no flag, physical stock above zero, not a Mintsoft product), and a plan token derived from the whole plan. Mintsoft is read with GET only through the lifecycle review's guarded reader; nothing is written.
- The Mintsoft write is not built: `--execute` is refused, because the request that sets a product's discontinued flag is unverified (docs/first-load-input-spec.md lists what is unknown).
