### Remove the retired QuickBooks connector's residue (accounting)
- Live code, types, settings keys, UI labels, tests and comments no longer name QuickBooks. Xero is the one registered accounting connector; the generic multi-connector design (registry, `AccountingConnectorId`, unregistered-connector handling) is unchanged. `archive/connectors/` and the `docs/archive/` removal notes are kept.
- New migration `20261122140000_purge_retired_accounting_settings` deletes the `plugin_quickbooks_enabled` and `quickbooks_*` rows from `settings`. Nothing in the build reads them; with the rows gone, the retired credential key and the retired realm pin leave the sensitive-key and binding-key lists. Historical rows in other tables that name the retired connector are left alone and read through the generic unregistered-connector paths.
- Historical rows of a connector this build does not register: connector labels in the sync banners and the retry dialog show the raw id; the "Accounting follow-ups owed, with nothing to re-drive them" backlog now lists every connector without a bound sweep (not a named list), with the fail-safe READ AND ESCALATE remedy; a mirrored discount event from such a connector is refused as unreplayable; and the orphan sweep and the sale-cancel retirement stamp `abandonedBeforeRemoteCall` only on rows of a registered connector, so a retired connector's revision-0 row is retired unstamped (UNKNOWN), not read as proven not posted.
- A stored incident record under the retired connector's unrecorded-document action no longer gets a superseding remedy (which named a setting and a panel that no longer exist). It is still never deleted: the action is on a short list of retired incident actions that the activity-log retention exemption and the factory reset spread, and the reset breadcrumb counts such records separately, because each is the only local trace of an effect that ledger accepted.
- The WooCommerce coupon ledger hand-off gives Xero's menu paths only for a Xero document; any other or unknown ledger gets neutral steps.
- The first-install rehearsal guard keeps refusing the retired connector's `QB_*` / `QUICKBOOKS*` environment prefixes, like the other retired connectors'.
- Xero behaviour is unchanged.

Docs: none — the help-docs and current docs purge ships in the companion PR on branch chore/purge-quickbooks-docs, kept separate to keep this diff reviewable.
